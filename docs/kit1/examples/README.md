# Synthetische Formatbeispiele

Die Telemetriewerte sind frei erfundene Testdaten für den Parser. Sie sind weder
Messwerte noch Zielbudgets, geographische Referenzen oder eine Kameraentscheidung.
Produktabnahme muss synthetische Daten zurückweisen. Die leeren Vorlagen unter
`templates/` sind ebenfalls kein Produktnachweis.

`coverage.synthetic.json` ist eine ausdrücklich synthetische, offene regionale
Berichtsstruktur. Ihr noch ungebundener regionaler Bezugsrahmen ist ein Vorlagenwert und keine vorhandene
Datenabdeckung. `represented_fraction` und NoData bleiben unbekannt; keine
Vollständigkeit wird aus dem leeren Beispiel abgeleitet.

`tiles.synthetic.json` ist eine leere, ausdrücklich synthetische Struktur für
interne Tileprobes. Keine reale Tilegröße, Datenzuordnung oder Rasterfunktion wird
damit nachgewiesen. Die Bildansicht bleibt ohne GUI/Raster/Modi.
